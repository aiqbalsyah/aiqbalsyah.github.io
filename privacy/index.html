Content Studio

Content Studio is a personal tool I use to publish my own writing and short videos to my own accounts on LinkedIn, Medium, Instagram, Facebook and YouTube. It is not offered to anyone else, and only I sign in to it.

When I connect an account, the tool asks only for the permissions it needs to publish to that account (for YouTube: uploading videos and reading my own channel's basic details). It uses them only to publish content I have approved and to confirm that it was published.

  • Access tokens are stored in the macOS Keychain on my own computer. They are not sent anywhere except to the platform they belong to.
  • No personal data from these accounts, or from anyone who views or comments on my posts, is collected, sold, shared or used for advertising.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Access can be removed at any time from each platform's security settings (for Google: myaccount.google.com/permissions), which deletes the tool's ability to use it.

YouTube API Services

Content Studio uses the YouTube API Services to upload my own videos to my own YouTube channel, Ardiansyah Iqbal. By using it, I agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

  • What is accessed: the permission to upload videos (youtube.upload) and to read my own channel's name and ID (youtube.readonly), only to confirm which channel is connected.
  • What is stored: only the OAuth refresh token, in the macOS Keychain on my computer. No YouTube data (videos, comments, viewers, analytics) is stored, shared or shown to anyone.
  • Deleting access and data: access can be revoked at any time at security.google.com/settings/security/permissions. Revoking it, or removing the tool, deletes the stored token; there is no other stored data to delete. Any request about data can be sent to the contact below and is handled within 7 days.
